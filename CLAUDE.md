
  # testing-agentcore
  
  ## Project
  
  Build a **basic web app** that displays **"Hello, Gabe"** on the page.

  ## Requirements

  - A single web page that renders the text: **Hello, Gabe**
  - Keep it minimal — a simple static site is fine
  - Plain **HTML** (optionally a little CSS to center/style the text); no framework or build step required
  
  ## Suggested structure

  - `index.html` — the page, containing a heading that reads `Hello, Gabe`

  ## Conventions

  - Keep the implementation as small and readable as possible
  - No external dependencies unless necessary

  ## Definition of done

  - Opening `index.html` in a browser shows **Hello, Gabe**
